CSS Overview

Overview of CSS

  • CSS, which stands for Cascading Style Sheets, is a crucial component of modern web development
  • It is a markup language used to apply styles for HTML
  • HTML is the structure of the web page, CSS is what makes it look good.
  • Primary role of CSS is to separate the content of a web page from its visual presentation. The separation allows web developers to create more flexible and maintainable websites.
  • With CSS you can control the layout, colors, fonts, and overall visual appearance of web pages without altering the HTML structure.
  • CSS is the language used to style an HTML document.
  • Styles can include properties like color, font, size, and many more. By changing these properties, you can dramatically alter how a web page looks without changing its content.
  • One of the most powerful aspects of CSS is its ability to create responsive designs.
  • Styles can be inherited and overridden, allowing for a hierarchical structure of styling. This is where the term cascading comes from.
  • You can use CSS. To make your website look great on any device, whether it's on desktop computer, a tablet or a smartphone.
  • adding a style element within the head element allows you to have control over the presentation of the webpage content.
  • You can add style to an element by specifying it in the style element
  • there will be many more styles, it's best to put all the styles in a separate file and link to it.
  • For the styling of the page to look similar on mobile as it does on a desktop or laptop, you need to add a meta element with a special content attribute.
  • The div element is used mainly for design layout purposes, unlike the other content elements you have used so far
  • You can use the id selector to target a specific element with an id attribute
  • ?A class selector is defined by a name with a dot directly in front of it.
  • inline-block elements only take up the width of their content.

Code Keywords

  • Selector: The HTML element you want to style (e.g., h1, p, .class, #id)
  • Property: The aspect of the element you want to change (e.g., color, font-size)
  • Value: The specific setting for the property (e.g., red, 16px)
  • Unit: The measurement used for the value (e.g., px, em, %)
  • Box Model: The structure that defines how elements are displayed, including content, padding, border, and margin.
  • Class Selector: A selector that targets elements with a specific class attribute, denoted by a dot (.) before the class name.
  • ID Selector: A selector that targets a unique element with a specific id attribute, denoted by a hash (#) before the id name.

Code examples

  • h1 { color: blue; }
  • .class { font-size: 16px; }
  • #id { margin: 10px; }
  • head { background-color: lightgray; }
  • meta { width: device-width; }
  • div { margin: 0 auto; }
  • body { font-family: Arial, sans-serif; }
  • span { display: inline; }
  • p { padding: 5px; }
  • h2 { margin: 20px 0; }
  • h3 { font-size: 18px; }
