CSS Fonts Overview

Overview of CSS Fonts

  • The font-family property in CSS is used to specify the font of an element's text.
  • You can specify multiple font names as a fallback system, in case the preferred font is not available.
  • Common generic font families include serif, sans-serif, monospace, cursive
  • You can change the font-family of text, to make it look different from the default font of your browser. Each browser has some common fonts available to it.
  • You can add a fallback value for the font-family by adding another font name separated by a comma. Fallbacks are used in instances where the initial is not found/available.
  • The typography of heading elements (e.g. h1, h2) is set by default values of users' browsers.
