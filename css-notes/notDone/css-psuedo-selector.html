CSS Psudeo Selectors

Overview of Psudeo Selectors

  • CSS pseudo-selectors are keywords added to selectors that specify a special state of the selected elements.
  • Pseudo-selectors are used to define the special state of an element.
  • Common pseudo-selectors include :hover, :active, :focus, :visited, :first-child, :last-child, and :nth-child().
  • The :hover pseudo-selector applies styles when the user hovers over an element with a pointing device.
  • The :active pseudo-selector applies styles when an element is being activated by the user, such as when a button is being clicked.
  • The :focus pseudo-selector applies styles when an element has focus, such as when a user clicks on an input field.
  • Pseudo-selectors can be combined with other selectors to create more specific rules.
  • You change the properties of a link when the mouse hovers over them by using a pseudo-selector

Code examples

  • a:hover { color: red; }
  • button:active { background-color: blue; }
  • input:focus { border-color: green; }
  • a:visited { color: purple; }
  • p:first-child { font-weight: bold; }
  • p:last-child { font-style: italic; }
  • li:nth-child(2) { text-decoration: underline; }
