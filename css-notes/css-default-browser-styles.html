Overview

  • When you start working with HTML and CSS, you'll notice that some styles are applied to your web pages even before you write any CSS. These styles are called default browser styles.
  • Default browser styles provide basic formatting to ensure that HTML elements are displayed in a readable way across all browsers.
  • These styles can vary slightly from 1 browse to another, which is why it's important to understand them when designing a consistent look for your website.
  • Headings are the most commonly used. HTML elements and are style by default to have varying sizes and weights.
  • H1, the highest level heading is usually bold and larger in font size compared to lower level headings like H2, H3, and so on.
  • Another example. With default styles, is the hr element, which creates a horizontal rule often used to visually separate sections of content. Browsers generally apply a simple line style to this element.
  • Block quotes are used to indicate a section of text that is a quotation from another source. Browsers typically add indentation and sometimes italicize the text.
  • Another element with default stores is the anchor element, which is styled with a default blue color and underlining to make it recognizable as a link.
  • The unordered and ordered list elements have basic formatting for lists, including indentation and bullets or numbers, depending on whether you're using an ordered or unordered list.

Keywords

default browser styles
Default browser styles are the built-in styles that web browsers apply to HTML elements when no custom CSS is provided. These styles ensure that web pages are displayed in a readable and consistent manner across different browsers.
headings
Headings are HTML elements that represent different levels of section titles. They range from H1 (the highest level) to H6 (the lowest level) and are styled by default to have varying sizes and weights.
horizontal rule
A horizontal rule is an HTML element represented by the <hr> tag. It creates a horizontal line on the page, often used to visually separate sections of content. Browsers typically apply a simple line style to this element.
block quotes
Block quotes are HTML elements represented by the <blockquote> tag. They are used to indicate a section of text that is a quotation from another source. Browsers typically add indentation and sometimes italicize the text within block quotes.
anchor element
The anchor element is an HTML element represented by the <a> tag. It is used to create hyperlinks, allowing users to navigate from one page to another. By default, browsers style anchor elements with a blue color and underlining to make them recognizable as links.
unordered list
An unordered list is an HTML element represented by the <ul> tag. It is used to create a list of items that do not have a specific order. Browsers typically format unordered lists with indentation and bullet points.
ordered list
An ordered list is an HTML element represented by the <ol> tag. It is used to create a list of items that have a specific order. Browsers typically format ordered lists with indentation and numbers to indicate the order of the items.
