Overview

  • CSS, which stands for Cascading Style Sheets, is a crucial component of modern web development
  • It is a markup language used to apply styles for HTML
  • HTML is the structure of the web page, CSS is what makes it look good.
  • Primary role of CSS is to separate the content of a web page from its visual presentation. The separation allows web developers to create more flexible and maintainable websites.
  • With CSS you can control the layout, colors, fonts, and overall visual appearance of web pages without altering the HTML structure.
  • CSS is the language used to style an HTML document.
  • CSS can be applied to a web page in three main ways: inline, internal, or external.
  • Inline CSS is written directly within an HTML element using the style attribute. It applies styles to a specific element.
  • Inline CSS is genuinely used for quick one off style's or to override other styles for a specific element.
  • Inline CSS should be avoided in most cases because it can clutter the HTML and make the code harder to maintain.
  • Most of the time it's better to use internal or external CSS to keep your stores organized and maintainable.
  • Internal CSS is written within the style tags inside the head section of a HTML document. It applies styles to the entire page and is useful when you need to style a single document.
  • Internal CSS is best used when you need to apply stars to a specific page rather than across multiple pages. It is useful for single page websites or when the styles don't need to be reused elsewhere.
  • There are some downsides to internal CSS, such as not promoting reusability across multiple pages. Additionally, like inline CSS in mixes, HTML and CSS, making the code harder to maintain in larger projects.
  • External CSS is written in a separate CSS file and linked to the HTML document using the link element in the head section.
  • External CSS Allows you to store multiple pages consistently and is the preferred method in professional web development.
  • External CSS is ideal for large projects where you want to maintain a consistent style across all the pages.
  • External CSS promotes separation of concerns by having HTML until the structure and CSS handle the styling, which makes the code more maintainable and scalable.
  • Styles can include properties like color, font, size, and many more. By changing these properties, you can dramatically alter how a web page looks without changing its content.
  • One of the most powerful aspects of CSS is its ability to create responsive designs.
  • Styles can be inherited and overridden, allowing for a hierarchical structure of styling. This is where the term cascading comes from.
  • You can use CSS. To make your website look great on any device, whether it's on desktop computer, a tablet or a smartphone.
  • adding a style element within the head element allows you to have control over the presentation of the webpage content.
  • You can add style to an element by specifying it in the style element
  • there will be many more styles, it's best to put all the styles in a separate file and link to it.
  • For the styling of the page to look similar on mobile as it does on a desktop or laptop, you need to add a meta element with a special content attribute.
  • The div element is used mainly for design layout purposes, unlike the other content elements you have used so far
  • You can use the id selector to target a specific element with an id attribute
  • ?A class selector is defined by a name with a dot directly in front of it.
  • inline-block elements only take up the width of their content.
  • All the styles are made up of various CSS rules.
  • A CSS rule is made up of two main parts. A selector and a declaration block.
  • A selector is a pattern used in CSS to identify and target specific HTML elements for styling.
  • Examples of selectors include type selectors, class selectors, and ID selectors.
  • The curly brace is provided in the basic syntax are known as declaration blocks. A declaration block applies a set of styles for a given selector or selectors.
  • Inside the declaration blocks you will have a series of declarations. Each declaration consists of a property and a value.
  • The property is the CSS identifier that specifies which feature is being styled.
  • The value would be a specific setting applied to that property. For example, if a property has a background color, a value of would be purple. Which will then set the background to purple.
  • After each property name you need to place a colon and after each value you should have a semi colon.
  • And an ID selector should start with a hash symbol.
  • All class selectors must start with a dot.
  • Inline elements only take up the width of their content.
  • Block elements take up the full width available.

Keywords

Selectors
Selectors are patterns used in CSS to select and style specific HTML elements.
Properties
Properties are the aspects of an element that you want to change, such as color or font-size.
Values
Values are the specific settings for properties, such as red for color or 16px for font-size.
Units
Units are the measurements used for values, such as px, em, or %.
Box Model
The box model is the structure that defines how elements are displayed, including content, padding, border, and margin.
Classes
Classes are used to apply styles to multiple elements with the same class attribute.
IDs
IDs are used to apply styles to a unique element with a specific id attribute.
Inline Elements
Inline elements only take up as much width as necessary and do not start on a new line.
Block Elements
Block elements take up the full width available and start on a new line.
Inline-Block Elements
Inline-block elements behave like inline elements but can have width and height set.
External CSS
External CSS is a separate CSS file linked to an HTML document.
Internal CSS
Internal CSS is written within a <style> tag in the head section of an HTML document.
Inline CSS
Inline CSS is applied directly to an HTML element using the<style> attribute.
Responsive Design
Responsive design is the practice of designing web pages that adapt to different screen sizes and devices.

Code Keywords

  • Selector: The HTML element you want to style (e.g., h1, p, .class, #id)
  • Property: The aspect of the element you want to change (e.g., color, font-size)
  • Value: The specific setting for the property (e.g., red, 16px)
  • Unit: The measurement used for the value (e.g., px, em, %)
  • Box Model: The structure that defines how elements are displayed, including content, padding, border, and margin.
  • Class Selector: A selector that targets elements with a specific class attribute, denoted by a dot (.) before the class name.
  • ID Selector: A selector that targets a unique element with a specific id attribute, denoted by a hash (#) before the id name.
  • Inline Elements: Elements that only take up as much width as necessary and do not start on a new line (e.g., span, a).
  • Block Elements: Elements that take up the full width available and start on a new line (e.g., div, p, h1).
  • Inline-Block Elements: Elements that behave like inline elements but can have width and height set (e.g., img, button).
  • Responsive Design: The practice of designing web pages that adapt to different screen sizes and devices.
